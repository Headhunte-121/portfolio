03. WORKFLOW

How I Build With AI

AI tools work best with clear architecture, small tasks, and careful verification. This is the four-step workflow I follow from idea to finished software.

STEP 01

Plan the Architecture & Break Down Features

Planning

Clear specifications first: Vague, large prompts produce poor code. Before writing any code, I plan the architecture, split features into modular pieces, and define the boundaries between components.

In WatchMark

Broke down the application into distinct modular services (TMDb metadata client, SQLite storage, VLC loopback bridge, and React frontend) so each part could be built and tested independently.

STEP 02

Manage AI Context & Keep It on Task

Execution

One task at a time: On large projects, AI tools can lose context or add unnecessary dependencies. I give them small, focused tasks with clear constraints to keep the codebase manageable.

In WatchMark

Built the application feature by feature against discrete milestones and GitHub issues, which kept the codebase focused over several weeks.

STEP 03

Audit Scope & Verify Completion

Code Audit

Verify against the spec: Generated code can leave placeholder comments, stubbed methods, or missing error handling. I review each change to confirm the feature is fully and correctly implemented.

In WatchMark

While reviewing the custom video player, I found that it loaded whole multi-gigabyte files into memory and left // TODO stubs for connection drops. I replaced this with 1 MB chunked Range streaming (bytes=start-end) and real error handling before merging.

STEP 04

Hands-On QA & Defect Hunting

Testing

Test on real hardware: Code that compiles can still fail on real machines. Drawing on my QA experience, I test the live build on physical hardware to catch bugs, memory leaks, and performance problems that automated checks miss.

In WatchMark

Automated tests passed, but testing the live build on physical hardware showed the idle window using 70.3% GPU in Windows Task Manager. I traced it in DevTools to an infinite CSS scale animation behind a blurred surface and brought idle GPU use down to 0.0%. I also found VLC resetting progress to 0 at the end credits and added a 90% threshold so completed episodes stay marked as watched.
