## 🌐 2-Minute Deployment to GitHub Pages

You can host this permanently for free on GitHub Pages at `https://headhunte-121.github.io`:

### Option A: The Root Portfolio (`Headhunte-121.github.io`)
1. Create a new public repository on GitHub named:  
   👉 `Headhunte-121.github.io`
2. Push the contents of this `portfolio/` folder directly to that repository:
   ```bash
   cd c:\OSINT\Tools\Personal\portfolio
   git init
   git branch -M main
   git remote add origin https://github.com/Headhunte-121/Headhunte-121.github.io.git
   git add .
   git commit -m "feat: initial portfolio deployment"
   git push -u origin main
   ```
3. Your portfolio will immediately go live at:  
   👉 `https://headhunte-121.github.io`

### Option B: Project Subdirectory (`Headhunte-121.github.io/portfolio`)
1. Create a repo named `portfolio`.
2. Go to **Settings $\rightarrow$ Pages $\rightarrow$ Deploy from branch (`main` / `/root`)**.
